The Choice Point

An interactive take on Russ Harris's Choice Point diagram from Acceptance and Commitment Therapy (ACT). Situations fall — you sort them Towards or Away under time pressure. Then the game stops and asks if you were sure.

The arcade isn't the teacher. The pauses are.

Built with HTML Canvas — all graphics are procedurally drawn, no sprites or images.
